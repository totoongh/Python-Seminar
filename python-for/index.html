for-Schleife · Schritt 1

Wozu braucht man eine Schleife?

Stell dir vor, du sollst drei Kolleginnen begrüßen. Ohne Schleife schreibst du dreimal fast dieselbe Zeile. Mit Schleife schreibst du sie einmal – und Python wiederholt sie für dich.

Lesen

Ohne Schleife: viel Tipparbeit

print("Hallo Ali")
print("Hallo Bea")
print("Hallo Cem")
Ausgabe
Hallo Ali
Hallo Bea
Hallo Cem

Das geht bei 3 Namen. Aber bei 30? Oder wenn du gar nicht weißt, wie viele Namen es sind?

Lesen

Mit Schleife: einmal schreiben

namen = ["Ali", "Bea", "Cem"]
for name in namen:
    print("Hallo", name)
Ausgabe
Hallo Ali
Hallo Bea
Hallo Cem

Lies die Schleife laut wie einen deutschen Satz:

„Für jeden name in der Liste namen: gib Hallo und den Namen aus.“

Das ist die ganze Idee. Eine for-Schleife heißt immer: „Mach das Gleiche für jedes Ding in einer Sammlung.“

Merken

Die Alltags-Übersetzung

  • Für jeden Brief im Stapel: Briefmarke draufkleben.
  • Für jedes Paket auf der Palette: Etikett scannen.
  • Für jede Schraube im Karton: festziehen.

Immer gleich: ein Stapel von Dingen + eine Tätigkeit, die mit jedem Ding gemacht wird.

for-Schleife · Schritt 2

Der Aufbau – Stück für Stück

Jede for-Schleife besteht aus denselben vier Teilen. Wenn du die erkennst, kannst du jede Schleife lesen.

Lesen

Die vier Teile

for name in namen:
    print("Hallo", name)
  • for … in … : – die festen Wörter. Der Doppelpunkt am Ende ist Pflicht.
  • name – die Laufvariable. Ein Zettel, auf dem bei jedem Durchlauf das nächste Ding steht.
  • namen – die Sammlung, die abgearbeitet wird.
  • eingerückter Block – das, was für jedes Ding gemacht wird (4 Leerzeichen).
Lesen

Was passiert Schritt für Schritt?

zahlen = [4, 7, 9]
for zahl in zahlen:
    print(zahl * 2)
print("Fertig")
Ausgabe
8
14
18
Fertig
Durchlaufzahl ist …Python rechnetAusgabe
144 * 28
277 * 214
399 * 218
Liste leer–Schleife endetFertig

Python macht das ganz stur: nächstes Ding nehmen → in die Laufvariable legen → Block ausführen → von vorn. Wenn nichts mehr da ist, geht es unter der Schleife weiter.

Wichtig

Die Laufvariable ist nur ein Name

for x in ["Ali", "Bea"]:
    print(x)

for banane in ["Ali", "Bea"]:
    print(banane)
Ausgabe
Ali
Bea
Ali
Bea

Beide Schleifen machen genau dasselbe. Python ist der Name egal – du wählst ihn. Nimm einen Namen, der beschreibt, was drinsteckt: for name in namen, for preis in preise.

Wichtig

Die Einrückung entscheidet: drin oder draußen?

for n in [1, 2, 3]:
    print("in der Schleife", n)
print("nach der Schleife")
Ausgabe
in der Schleife 1
in der Schleife 2
in der Schleife 3
nach der Schleife

Eingerückt = wird jedes Mal ausgeführt. Nicht eingerückt = wird einmal ausgeführt, wenn die Schleife fertig ist.

for-Schleife · Schritt 3

range(): Zahlen statt Liste

Manchmal hast du keine Liste, sondern willst einfach etwas 5-mal tun oder von 1 bis 10 zählen. Dafür gibt es range(). Es liefert Zahlen – so, als hättest du eine Liste mit Zahlen hingeschrieben.

Lesen

range(5) – fünf Durchläufe

for i in range(5):
    print(i)
Ausgabe
0
1
2
3
4

Zwei Dinge überraschen fast jeden am Anfang:

  • Es geht bei 0 los.
  • Die 5 selbst ist nicht dabei. Es sind trotzdem genau 5 Zahlen: 0, 1, 2, 3, 4.

Denk dir: range(5) = „fünf Durchläufe“.

Lesen

Einfach nur wiederholen

for i in range(3):
    print("Klopf")
Ausgabe
Klopf
Klopf
Klopf

Hier wird i gar nicht benutzt. Die Schleife dient nur als Zähler: „Mach das dreimal.“ Der Name i ist dafür üblich.

Lesen

range(start, stopp) – von … bis …

for zahl in range(1, 6):
    print(zahl)
Ausgabe
1
2
3
4
5

Erste Zahl = Start (ist dabei). Zweite Zahl = Stopp (ist nicht mehr dabei). Willst du bis 5 zählen, schreibst du also 6.

Eselsbrücke: „Bis vor den Stopp.“

Lesen

range(start, stopp, schritt) – in Sprüngen

for zahl in range(0, 11, 5):
    print(zahl)

for zahl in range(3, 0, -1):
    print(zahl)
Ausgabe
0
5
10
3
2
1

Die dritte Zahl ist die Schrittweite. Mit -1 zählst du rückwärts.

for-Schleife · Muster 1

Sammeln: Summe und Zähler

Bisher hat die Schleife nur ausgegeben. Jetzt soll sie etwas ausrechnen. Dafür gibt es ein Muster, das du immer wieder brauchst: Du legst vor der Schleife eine Variable an und veränderst sie in der Schleife.

Lesen

Das Sparschwein-Muster

preise = [3, 5, 2]
summe = 0
for preis in preise:
    summe = summe + preis
print("Gesamt:", summe)
Ausgabe
Gesamt: 10
Durchlaufpreissumme vorhersumme nachher
Start––0
1303
2538
32810

Stell dir summe als Sparschwein vor:

  1. Vor der Schleife: leeres Sparschwein hinstellen (summe = 0).
  2. In der Schleife: jedes Mal etwas einwerfen (summe = summe + preis).
  3. Nach der Schleife: reinschauen (print(summe)).
Lesen

summe = summe + preis – wie liest man das?

Das ist keine Gleichung aus Mathe! Lies es von rechts nach links:

„Nimm den alten Wert von summe, zähle preis dazu und speichere das Ergebnis als neuen Wert von summe.“

Die Kurzform summe += preis bedeutet genau dasselbe.

Lesen

Zählen ist dasselbe Muster

namen = ["Ali", "Bea", "Cem", "Dana"]
anzahl = 0
for name in namen:
    anzahl = anzahl + 1
print("Es sind", anzahl, "Personen")
Ausgabe
Es sind 4 Personen

Statt des Wertes wird einfach jedes Mal 1 eingeworfen.

Typische Fehler

Drei Fallen

  • summe = 0 in der Schleife: Dann wird das Sparschwein in jedem Durchlauf geleert.
  • summe = 0 vergessen: Python kennt summe noch nicht → NameError.
  • print(summe) eingerückt: Dann siehst du jeden Zwischenstand statt nur das Ergebnis.

for-Schleife · Muster 2

Auswählen: if in der Schleife

Oft willst du nicht mit allen Dingen etwas tun, sondern nur mit manchen. Dann steckst du ein if in die Schleife. Die Schleife zeigt dir jedes Ding – das if entscheidet, ob etwas passiert.

Lesen

Jedes Ding wird geprüft

preise = [4, 12, 7, 20]
for preis in preise:
    if preis > 10:
        print(preis, "ist teuer")
Ausgabe
12 ist teuer
20 ist teuer
Durchlaufpreispreis > 10 ?Ausgabe
14nein–
212ja12 ist teuer
37nein–
420ja20 ist teuer

Achte auf die zwei Stufen der Einrückung: Das if gehört zur Schleife (4 Leerzeichen), das print gehört zum if (8 Leerzeichen).

Lesen

Zählen, was passt

noten = [2, 5, 1, 6, 3]
nicht_bestanden = 0
for note in noten:
    if note >= 5:
        nicht_bestanden = nicht_bestanden + 1
print("Nicht bestanden:", nicht_bestanden)
Ausgabe
Nicht bestanden: 2

Das ist Sparschwein + if: Es wird nur eingeworfen, wenn die Bedingung stimmt.

Lesen

Mit else: für jedes Ding eine von zwei Reaktionen

    if zahl % 2 == 0:
        print(zahl, "gerade")
    else:
        print(zahl, "ungerade")
Ausgabe

3 ungerade
4 gerade

zahl % 2 ist der Rest beim Teilen durch 2. Ist der Rest 0, ist die Zahl gerade.

for-Schleife · Schritt 8

Wann for – und wann while?

Beide Schleifen wiederholen etwas. Der Unterschied ist, woher das Ende kommt.

Lesen

Die eine Frage, die alles entscheidet

„Weiß ich vorher, wie oft oder worüber wiederholt wird?“

Ja → for

Es gibt eine Liste, einen Text oder eine feste Anzahl.

  • für jeden Namen in der Liste
  • 10-mal
  • von 1 bis 100
Nein → while

Es hängt von etwas ab, das erst während des Programms passiert.

  • bis der Nutzer „ende“ eingibt
  • solange das Passwort falsch ist
  • bis das Sparziel erreicht ist
Lesen

Dasselbe Programm – zweimal

for i in range(1, 4):
    print(i)
Ausgabe
1
2
3
i = 1
while i < 4:
    print(i)
    i = i + 1
Ausgabe
1
2
3

Bei while musst du dich um drei Dinge selbst kümmern: Startwert, Bedingung, Hochzählen. Bei for erledigt range das alles. Darum ist for beim Zählen kürzer und sicherer – eine Endlosschleife kann dir kaum passieren.

Übersicht

Typische Einsatzfälle für for

  • Alles ausgeben: jede Zeile einer Liste anzeigen
  • Etwas n-mal tun: 3 Versuche, 5 Runden, 10 Zeilen
  • Zusammenrechnen: Summe, Durchschnitt, Anzahl
  • Aussortieren: nur die teuren, nur die bestandenen
  • Bestes finden: größter, kleinster, längster
  • Umwandeln: aus einer Liste eine neue machen
  • Tabelle erzeugen: Einmaleins, Preisliste
