Klausurvorbereitung · Abschnitt 1

Wahrheitswerte verstehen

Aus einzelnen Vergleichen werden zusammengesetzte Bedingungen. Bestimme erst die Teilwerte, dann den Wert des gesamten Ausdrucks.

Verstehen

1. Was ist ein Wahrheitswert?

Eine Bedingung beantwortet eine Ja-Nein-Frage: Ist die Zahl größer als 10? Ist ein Name gleich „Ali“? In Python heißen die beiden Wahrheitswerte True (wahr) und False (falsch). Beide haben den Datentyp bool. Großschreibung ist wichtig.

punkte = 58
bestanden = punkte >= 50
print(bestanden)
print(type(bestanden))

Die Ausgaben sind True und <class 'bool'>. Der Vergleich wird zuerst ausgewertet: Python bestimmt seinen Wert. Dieser Wert wird in bestanden gespeichert. print zeigt ihn anschließend an.

Ein gespeicherter bool-Wert und der Text "True" sind unterschiedliche Dinge: Der Text hat den Datentyp str.

Verstehen

2. Zwei Bedingungen verbinden

and ist nur wahr, wenn beide Bedingungen wahr sind. or ist wahr, wenn mindestens eine wahr ist, also auch, wenn beide wahr sind. not kehrt einen Wahrheitswert um.

Eine Wahrheitstafel zeigt jede mögliche Kombination. Bei zwei Werten sind das vier Zeilen: Jeder Wert kann unabhängig True oder False sein.

ABA and BA or B
FalseFalseFalseFalse
FalseTrueFalseTrue
TrueFalseFalseTrue
TrueTrueTrueTrue
Anot A
FalseTrue
TrueFalse

Hier stehen A und B für bool-Variablen. Arbeite in diesem Kapitel nur mit bool-Werten und Vergleichen. So sind die Ergebnisse der logischen Verknüpfungen wieder bool-Werte.

Verstehen

3. Drei Wahrheitswerte Schritt für Schritt

Drei Werte ergeben acht Kombinationen: 2 · 2 · 2 = 8. Für jede Tabellenzeile wertest du denselben Ausdruck mit den Werten dieser Zeile aus.

Beispiel: A = True, B = False, C = True. Gesucht ist (A or B) and not C.

  1. Klammer: True or False ergibt True.
  2. Verneinung: not True ergibt False.
  3. Verbindung: True and False ergibt False.

Das Ergebnis des gesamten Ausdrucks ist also False. Das Ergebnis einer Teilbedingung ist noch nicht das Gesamtergebnis.

Reihenfolge: zuerst Klammern, bei logischen Verknüpfungen anschließend not, dann and, dann or. Zum Beispiel bedeutet A or B and C dasselbe wie A or (B and C). Schreibe Klammern, wenn du deine Absicht deutlich machen möchtest.

Python kann die Auswertung abkürzen: Bei False and … steht das Ergebnis schon fest, ebenso bei True or …. Für die Wahrheitstafel kannst du die Teilwerte trotzdem einzeln bestimmen.

Klausurvorbereitung · Abschnitt 2

Schleifen umwandeln

Sichere die gewünschte Ausgabe, bevor du die Schleife ersetzt. Prüfe Startwert, Grenze und Schrittweite getrennt.

Verstehen

Was bleibt bei einer Umwandlung gleich?

Du wechselst die Schleifenart. Die ausgegebenen Werte, ihre Reihenfolge und die Anzahl der Durchläufe sollen gleich bleiben. Vergleiche auch, was nach der Schleife passiert.

  • while: Startwert vor der Schleife, Bedingung im Schleifenkopf, Veränderung im Block.
  • for mit range(start, stopp, schritt): Die Folge liefert die Laufwerte. Der Stoppwert ist ausgeschlossen.
  • Doppelpunkt hinter dem Schleifenkopf, eingerückter Schleifenblock. Eine Zeile danach wird nur einmal ausgeführt.

Die folgenden Aufgaben prüfen gleiche Ausgaben. Der Wert der Laufvariable nach der Schleife muss dabei nicht gleich sein. Eine Eingabeschleife mit unbekannter Wiederholungszahl lässt sich nicht einfach durch einen festen range ersetzen.

Übung 2: Von while zu for

Lies den Code und notiere zuerst seine vollständige Ausgabe. Schreibe anschließend einen vollständigen Code mit for und range(), der genau dieselbe Ausgabe erzeugt. Verwende kein while. „Ende“ soll genau einmal nach der Schleife erscheinen.

zahl = 10
while zahl > 0:
    print(zahl)
    zahl = zahl - 2
print("Ende")

Das Feld ist ein Schreibplatz. Der Code wird hier nicht ausgeführt und nicht gespeichert. Bearbeite die Aufgabe zuerst auf Papier oder hier; prüfe danach in Python.

Hinweis

Der Startwert ist 10, die Schrittweite −2. Der Stoppwert 0 gehört nicht mehr zur Ausgabe.

Musterlösung und Erklärung
for zahl in range(10, 0, -2):
    print(zahl)
print("Ende")

Die Ausgabe ist 10, 8, 6, 4, 2 und anschließend Ende, jeweils in einer eigenen Zeile. Die for-Schleife übernimmt das Wechseln zum nächsten Wert; zahl = zahl - 2 entfällt.

Übung 3: Von for zu while

Notiere zuerst die Ausgabe. Ersetze dann die for-Schleife durch eine while-Schleife und schreibe den vollständigen Code. Verwende weder for noch range(). Startwert, Bedingung und Veränderung der Laufvariable müssen selbst geschrieben werden. Die Ausgabe bleibt unverändert.

for zahl in range(3, 13, 3):
    print(zahl * 2)
print("Fertig")

Das Feld ist ein Schreibplatz. Der Code wird hier nicht ausgeführt und nicht gespeichert. Bearbeite die Aufgabe zuerst auf Papier oder hier; prüfe danach in Python.

Hinweis

Die Laufvariable nimmt die Werte 3, 6, 9 und 12 an. Ausgegeben wird jeweils ihr Doppeltes. Achte auf den Unterschied zwischen Laufwert und Ausgabewert.

Musterlösung und Erklärung
zahl = 3
while zahl < 13:
    print(zahl * 2)
    zahl = zahl + 3
print("Fertig")

Ausgabe: 6, 12, 18, 24, Fertig. Jede Zahl steht in einer eigenen Zeile. Auch zahl <= 12 passt hier. Ohne die Veränderung um +3 würde die while-Schleife nicht enden.

Klausurvorbereitung · Abschnitt 3

Rechnen und zählen mit Funktionen

Vier Schreibaufgaben: eine Rechenfunktion und eine Zählfunktion mit while sowie jeweils eine mit for. Teste auch Fälle ohne Schleifendurchlauf.

Verstehen

Funktion, Summe und Rückgabe

Eine Funktion bekommt Werte als Parameter, rechnet damit und liefert mit return ihr Ergebnis zurück. Die Testaufrufe stehen außerhalb der Funktion. Dort kann print die Rückgabe anzeigen.

Eine Summe speichert ein bisheriges Rechenergebnis. Ein Zähler zählt Treffer. Beide beginnen hier bei 0, werden im Schleifenblock verändert und erst nach der Schleife zurückgegeben. Ein return im Schleifenblock würde die Funktion schon beim ersten erreichten return beenden.

Schreibe bei den vier Aufgaben jeweils Definition und Testaufrufe. Verwende def, die vorgegebene Schleifenart und return. Nutze kein sum(), keine Comprehension und keine fertige Zählmethode.

Übung 4: Rechnen mit while: Summe bis n

Schreibe summe_bis(n). Der Parameter n ist eine ganze Zahl ab 0. Addiere mit einer while-Schleife alle ganzen Zahlen von 1 bis einschließlich n und gib die Summe zurück. Für n = 0 soll 0 zurückgegeben werden.

TestaufrufErwartete Rückgabe
summe_bis(0)0
summe_bis(1)1
summe_bis(5)15

Das Feld ist ein Schreibplatz. Der Code wird hier nicht ausgeführt und nicht gespeichert. Bearbeite die Aufgabe zuerst auf Papier oder hier; prüfe danach in Python.

Hinweis

Starte die Summe bei 0 und die Laufvariable bei 1. Nach jeder Addition erhöht sich die Laufvariable um 1. Liegt der Start schon über n, gibt es keinen Durchlauf.

Musterlösung und Erklärung
def summe_bis(n):
    summe = 0
    zahl = 1
    while zahl <= n:
        summe = summe + zahl
        zahl = zahl + 1
    return summe

print(summe_bis(0))
print(summe_bis(1))
print(summe_bis(5))

summe ist nach jedem Durchlauf die Summe der bisher besuchten Zahlen. Bei n = 0 wird der Schleifenblock übersprungen.

Übung 5: Rechnen mit for: Quadrate addieren

Schreibe quadratsumme(n). Der Parameter n ist eine ganze Zahl ab 0. Addiere mit for und range() die Quadrate aller ganzen Zahlen von 1 bis einschließlich n. Das Quadrat einer Zahl erhältst du mit zahl * zahl. Gib das Ergebnis zurück. Für n = 0 soll das Ergebnis 0 sein.

TestaufrufErwartete Rückgabe
quadratsumme(0)0
quadratsumme(1)1
quadratsumme(3)14

Das Feld ist ein Schreibplatz. Der Code wird hier nicht ausgeführt und nicht gespeichert. Bearbeite die Aufgabe zuerst auf Papier oder hier; prüfe danach in Python.

Hinweis

Damit n besucht wird, muss der ausgeschlossene Stoppwert n + 1 sein. Die Summe wächst um das Quadrat, nicht um 1.

Musterlösung und Erklärung
def quadratsumme(n):
    summe = 0
    for zahl in range(1, n + 1):
        summe = summe + zahl * zahl
    return summe

print(quadratsumme(0))
print(quadratsumme(1))
print(quadratsumme(3))

Für n = 3 rechnest du 1 · 1 + 2 · 2 + 3 · 3 = 14. Bei n = 0 ist range(1, 1) leer.

Übung 6: Zählen mit while: Positive Werte

Schreibe zaehle_positive(werte). werte ist eine flache Liste ganzer Zahlen. Besuche alle Elemente mit einer while-Schleife und einem Index. Zähle, wie viele Werte größer als 0 sind, und gib die Anzahl zurück. Die Zahl 0 zählt nicht mit. Verändere die Liste nicht; für eine leere Liste ist das Ergebnis 0.

TestaufrufErwartete Rückgabe
zaehle_positive([])0
zaehle_positive([-2, 0, 5, 1, -7])2
zaehle_positive([4, 4])2

Das Feld ist ein Schreibplatz. Der Code wird hier nicht ausgeführt und nicht gespeichert. Bearbeite die Aufgabe zuerst auf Papier oder hier; prüfe danach in Python.

Hinweis

Du brauchst zwei Variablen: anzahl für die Treffer, index für die Position. index wächst in jedem Durchlauf, auch wenn der Wert nicht positiv ist.

Musterlösung und Erklärung
def zaehle_positive(werte):
    anzahl = 0
    index = 0
    while index < len(werte):
        if werte[index] > 0:
            anzahl = anzahl + 1
        index = index + 1
    return anzahl

print(zaehle_positive([]))
print(zaehle_positive([-2, 0, 5, 1, -7]))
print(zaehle_positive([4, 4]))

Nur Treffer erhöhen anzahl. Der Index wächst unabhängig davon. index < len(werte) verhindert einen Zugriff hinter dem letzten Element.

Übung 7: Zählen mit for: Durch 3 teilbar

Schreibe zaehle_durch_drei(werte). werte ist eine flache Liste ganzer Zahlen. Gehe mit einer for-Schleife direkt über die Werte. Zähle die Werte, die ohne Rest durch 3 teilbar sind, und gib die Anzahl zurück. Benutze %. Auch 0 und negative Vielfache von 3 zählen mit. Verändere die Liste nicht; für eine leere Liste ist das Ergebnis 0.

TestaufrufErwartete Rückgabe
zaehle_durch_drei([])0
zaehle_durch_drei([3, 4, 6, 0, -3])4
zaehle_durch_drei([1, 2, 5])0

Das Feld ist ein Schreibplatz. Der Code wird hier nicht ausgeführt und nicht gespeichert. Bearbeite die Aufgabe zuerst auf Papier oder hier; prüfe danach in Python.

Hinweis

% liefert den Divisionsrest. Ein Rest von 0 bedeutet „ohne Rest teilbar“. Zähle die Treffer; addiere nicht die gefundenen Werte.

Musterlösung und Erklärung
def zaehle_durch_drei(werte):
    anzahl = 0
    for wert in werte:
        if wert % 3 == 0:
            anzahl = anzahl + 1
    return anzahl

print(zaehle_durch_drei([]))
print(zaehle_durch_drei([3, 4, 6, 0, -3]))
print(zaehle_durch_drei([1, 2, 5]))

Die vier Treffer im zweiten Test sind 3, 6, 0 und -3. Ihre Summe wäre 6, gesucht ist aber die Anzahl 4.
