Übung 1 · 12-Bit-Maschinenprogramm

Maschinenprogramm zusammenbauen

Erstelle ein Programm, das 6 + 9 berechnet und das Ergebnis an Speicheradresse 4 ablegt.

LOAD0001
ADD0010
STORE0011
Eine Anweisung hat 12 Bits: 4 Bits Opcode und 8 Bits für Wert oder Adresse.
1LOAD 6
2ADD 9
3STORE 4
✓

Du hast es geschafft!

0001 00000110
0010 00001001
0011 00000100

Die CPU lädt 6, addiert 9 und speichert 15 an Adresse 4.

Übung 2 · Prozessschritte ordnen

Was passiert bei python rechnung.py?

Bringe die Karten in eine sinnvolle Reihenfolge. Ziehe sie oder benutze die Pfeiltasten an den Karten.

  1. ⠿

    Die CPU führt die benötigten Maschinenanweisungen aus.

  2. ⠿

    Du tippst python rechnung.py.

  3. ⠿

    python.exe wird gefunden.

  4. ⠿

    Das Terminal zeigt die Ausgabe an.

  5. ⠿

    Das Terminal gibt die Zeichen an PowerShell weiter.

  6. ⠿

    Das Betriebssystem startet einen neuen Prozess.

  7. ⠿

    PowerShell übernimmt und untersucht den Befehl.

  8. ⠿

    Das Python-Programm erzeugt die Ausgabe.

  9. ⠿

    PowerShell sucht nach dem Befehl python.

Übung 3 · Prozessschritte ordnen

Was passiert bei git status?

Ordne auch diese Befehlskette. Achte darauf, wann PowerShell, Betriebssystem, Git, CPU und Terminal beteiligt sind.

  1. ⠿

    Das Terminal zeigt das Ergebnis.

  2. ⠿

    PowerShell erkennt git als Befehlsnamen und status als Argument.

  3. ⠿

    Git untersucht das aktuelle Verzeichnis.

  4. ⠿

    Du gibst git status ein.

  5. ⠿

    Die CPU führt Maschinenanweisungen aus.

  6. ⠿

    git.exe wird über einen Ordner aus PATH gefunden.

  7. ⠿

    Git schreibt sein Ergebnis.

  8. ⠿

    Das Betriebssystem startet git.exe als Prozess.

Übung 6 · Auf dem eigenen Windows-PC

PowerShell kennenlernen

Öffne PowerShell auf deinem Rechner und führe die Befehle nacheinander aus. Die Befehle lesen Informationen oder wechseln nur das aktuelle Verzeichnis. Sie verändern keine Dateien.

A

PowerShell und Zeit

Finde zuerst heraus, welche PowerShell-Version du verwendest.

$PSVersionTable.PSVersion
  • Welche Versionsnummer wird angezeigt?
  • Welche Hauptversion steht ganz vorne?
Get-Date
  • Welche Informationen liefert der Befehl?
  • Entspricht die Ausgabe deiner aktuellen Uhrzeit?
B

Aktuelles Verzeichnis

Get-Location
  • In welchem Verzeichnis befindest du dich?
  • Ist der angezeigte Pfad absolut oder relativ?
Get-ChildItem
  • Welche Dateien und Ordner erkennst du?
  • Woran unterscheidest du Dateien und Ordner?
dir
  • Vergleiche die Ausgabe mit Get-ChildItem.
C

Alias und Befehl unterscheiden

Get-Command dir
Get-Alias dir
  • Ist dir ein eigenständiges Programm?
  • Auf welchen PowerShell-Befehl verweist der Name?
Get-Command Get-Date
  • Welchen CommandType besitzt Get-Date?
D

Eine Ordnerebene wechseln

Wähle einen vorhandenen Ordner aus der Ausgabe von Get-ChildItem. Ersetze den Beispielnamen durch diesen Ordner.

Set-Location "Name-des-Ordners"
Get-Location
Set-Location ..
  • Wie verändert sich der aktuelle Pfad?
  • Was bewirkt ..?
  • Wann sind Anführungszeichen um einen Ordnernamen hilfreich?

Übung 7 · Programmdatei und Prozess

Notepad finden und im Terminal öffnen

Finde den Speicherort von Notepad, starte das Programm direkt aus PowerShell und untersuche den entstandenen Prozess.

1

Notepad als Befehl untersuchen

Get-Command notepad
  • Welcher CommandType wird angezeigt?
  • Was steht unter Name und Source?
Get-Command notepad | Select-Object Name, CommandType, Source
(Get-Command notepad).Source
2

Notepad aus PowerShell starten

notepad
  • Öffnet sich Notepad?
  • Musstest du den vollständigen Pfad eingeben?
  • Warum konnte PowerShell das Programm trotzdem finden?

Notepad nur öffnen. Du musst keine Datei erstellen oder speichern.

3

Den laufenden Prozess untersuchen

Lass Notepad geöffnet und wechsle zurück zu PowerShell.

Get-Process notepad
Get-Process notepad | Select-Object Name, Id, Path
  • Welche Prozess-ID wird angezeigt?
  • Welche Information steht unter Path?
  • Vergleiche den Pfad mit dem Ergebnis von Get-Command notepad.
4

Notepad schließen

Schließe Notepad über das normale X. Führe danach beide Befehle erneut aus.

Get-Process notepad
Get-Command notepad
  • Was ist beim Schließen verschwunden?
  • Was ist weiterhin vorhanden?
  • Was zeigt das über den Unterschied zwischen Programmdatei und Prozess?

Falls ein weiteres Notepad-Fenster geöffnet ist, kann weiterhin ein Notepad-Prozess erscheinen.

Übung 8 · Auf dem eigenen Windows-PC

PATH und Prozesse erkunden

Die Ergebnisse können sich von Rechner zu Rechner unterscheiden. Notiere Auffälligkeiten für die gemeinsame Besprechung.

A

Externe Programme finden

Get-Command git
Get-Command python
  • Werden beide Programme gefunden?
  • Welcher CommandType wird angezeigt?
  • Unter welchem vollständigen Pfad liegen sie?
  • Welche Meldung erscheint, wenn ein Programm nicht auffindbar ist?
B

Die PATH-Liste ansehen

$env:PATH -split ";"
  • Wie viele Ordner stehen ungefähr in der Liste?
  • Findest du einen Ordner, der zu Git oder Python gehört?
  • Warum durchsucht PowerShell mehrere Ordner?
C

Laufende Prozesse ansehen

Get-Process
  • Welche Programme erkennst du?
  • Gibt es mehrere Prozesse mit demselben Namen?
Get-Process | Select-Object -First 5 Name, Id
  • Was bewirkt Select-Object -First 5?
  • Besitzt jeder Prozess eine eigene ID?
D

Prozesse sortieren

Get-Process | Sort-Object CPU -Descending | Select-Object -First 5 Name, Id, CPU
  • Wonach wird sortiert?
  • Welcher Prozess steht auf deinem Rechner oben?
  • Warum können andere Personen ein anderes Ergebnis erhalten?

Optional

Get-Process | Get-Member
  • Welche weiteren Eigenschaften entdeckst du?
