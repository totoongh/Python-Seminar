Datentypen und Umwandlungen

Python muss wissen, ob ein Wert Text, eine Zahl oder ein Wahrheitswert ist. Der Datentyp legt fest, was Python damit tun kann.

strText"12", "Hallo"
intGanze Zahl12, -4
floatKommazahl12.5, 0.75
boolWahrheitswertTrue, False
Text wird aneinandergehängt
zahl = input("Zahl: ")
print(zahl + zahl)

# Eingabe 5 → Ausgabe 55
Text wird zur Zahl
zahl = int(input("Zahl: "))
print(zahl + zahl)

# Eingabe 5 → Ausgabe 10
input()liefert immer Text
→
int(text)ganze Zahl
oder
float(text)Kommazahl

Datentypen sichtbar machen:

alter = 17
preis = 2.50
name = "Mika"
angemeldet = True

print(type(alter))
print(type(preis))
print(type(name))
print(type(angemeldet))
Umwandlungen können scheitern. Bei int("fünf") weiß Python nicht, welche Zahl gemeint ist. Probiere bewusst gültige und ungültige Eingaben und lies die letzte Zeile der Fehlermeldung.

Entscheidungen mit elif und else

if prüft den ersten Fall, elif weitere Fälle und else fängt alles Übrige auf. Genau ein Zweig wird ausgeführt.

ifTrifft der erste Fall zu?
sonst →
elifTrifft dieser Fall zu?
sonst →
elseAlle übrigen Fälle

Mehrere Temperaturbereiche unterscheiden:

temperatur = int(input("Temperatur: "))

if temperatur < 0:
    print("Frost")
elif temperatur < 20:
    print("Kühl")
else:
    print("Warm")
Python prüft von oben nach unten. Sobald eine Bedingung passt, überspringt Python alle folgenden Zweige. Deshalb muss die Reihenfolge zu den Wertebereichen passen.
Reihenfolge verdeckt Fälle
if punkte >= 50:
    print("Bestanden")
elif punkte >= 90:
    print("Sehr gut")
Spezieller Fall zuerst
if punkte >= 90:
    print("Sehr gut")
elif punkte >= 50:
    print("Bestanden")
else:
    print("Nicht bestanden")

Python · Mehrere Prüfungen

Bedingungen miteinander verbinden

Mit and, or und not kann eine Entscheidung von mehreren Voraussetzungen abhängen.

andBeides muss stimmen

Alter passt und Ticket ist vorhanden.

orMindestens eins reicht

Passwort oder Ersatzcode stimmt.

notWahrheitswert umkehren

Nicht gesperrt bedeutet: Zugang möglich.

Mehrere Voraussetzungen gleichzeitig prüfen:

alter = int(input("Alter: "))
ticket = input("Ticket vorhanden? ")

if alter >= 18 and ticket == "ja":
    print("Einlass erlaubt")
else:
    print("Kein Einlass")
Wertebereich

Zwischen 10 und 20

if zahl >= 10 and zahl <= 20:
    print("Im Bereich")
Python-Kurzform

Dieselbe Prüfung

if 10 <= zahl <= 20:
    print("Im Bereich")

Python · Wiederholen

while-Schleifen

Eine while-Schleife wiederholt ihren eingerückten Block, solange ihre Bedingung True ergibt.

1Bedingung prüfen
→
2Block ausführen
→
3Wert verändern
↺

Eine Eingabe wiederholen, bis sie gültig ist:

antwort = input("links oder rechts? ")

while antwort != "links" and antwort != "rechts":
    print("Diese Antwort kenne ich nicht.")
    antwort = input("Bitte links oder rechts: ")

print("Gewählt:", antwort)
Zähler verändert sich
zahl = 1

while zahl <= 5:
    print(zahl)
    zahl = zahl + 1
Endlosschleife
zahl = 1

while zahl <= 5:
    print(zahl)

# zahl bleibt immer 1
Vor jedem Start fragen: Was muss sich im Schleifenblock verändern, damit die Bedingung irgendwann False wird?

Listen

Eine Liste speichert mehrere Werte in einer festen Reihenfolge. Jeder Wert besitzt eine Position, den sogenannten Index.

Index012 Wert"Hammer""Zange""Säge"

Liste anlegen, lesen und verändern:

werkzeuge = ["Hammer", "Zange", "Säge"]

print(werkzeuge[0])
print(len(werkzeuge))

werkzeuge.append("Bohrer")
werkzeuge[1] = "Kombizange"

print(werkzeuge)
liste[0]Wert lesen

Der erste Index ist immer 0.

append(wert)Wert anhängen

Der neue Wert landet am Ende.

len(liste)Länge ermitteln

Anzahl der gespeicherten Werte.

Typischer Fehler: Eine Liste mit drei Elementen besitzt die Indizes 0, 1 und 2. Der Zugriff auf Index 3 führt zu einem IndexError.

for-Schleifen

Eine for-Schleife nimmt nacheinander jeden Wert aus einer Liste. Mit range() kann sie auch eine festgelegte Zahlenfolge durchlaufen.

Werte einer Liste
namen = ["Aylin", "Ben", "Cem"]

for name in namen:
    print("Hallo", name)
Zahlen mit range
for zahl in range(1, 6):
    print(zahl)

# 1, 2, 3, 4, 5
Liste["A", "B", "C"]
→
Aktueller Wertwert
→
Blockeinmal pro Wert

Werte während der Schleife zusammenzählen:

preise = [4, 7, 3]
gesamt = 0

for preis in preise:
    gesamt = gesamt + preis

print("Gesamt:", gesamt)
while oder for? Verwende for, wenn alle Werte einer Sammlung oder eine feste Zahlenfolge verarbeitet werden. while passt, wenn vorher nicht feststeht, wie oft wiederholt werden muss.
