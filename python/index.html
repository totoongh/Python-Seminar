Python · Einstieg

Python installieren und Versionen verstehen

Python ist sowohl der Name einer Programmiersprache als auch eines Programms auf deinem Rechner. Dieses Programm liest und startet später unsere .py-Dateien.

Programmiersprache

Regeln zum Schreiben

Python legt fest, wie wir Anweisungen, Berechnungen und Bedingungen formulieren.

Python-Programm

Programm zum Ausführen

Der installierte Python-Interpreter liest unseren Quellcode und führt die benötigten Maschinenanweisungen aus.

Warum gibt es verschiedene Versionen? Python wird weiterentwickelt: Neue Möglichkeiten kommen hinzu, Fehler werden behoben und ältere Schreibweisen können irgendwann wegfallen. Im Kurs verwenden alle möglichst dieselbe von der IT freigegebene Python-3-Version.
1

Python über die vereinbarte Quelle oder das Softwarecenter der Schule installieren.

2

Falls der Installer danach fragt: Python zum PATH hinzufügen.

3

Ein neues PowerShell-Fenster öffnen und die Installation prüfen.

python --version
py --version

py ist auf vielen Windows-Rechnern ein zusätzlicher Startname für Python. Falls einer der beiden Befehle nicht funktioniert, notiere die Meldung.

Python · Schreibregeln

Syntax: Wie Python geschrieben werden muss

Syntax sind die Schreibregeln einer Sprache. Python kann nur Anweisungen ausführen, die zu diesen Regeln passen.

gültig
print("Hallo")
ungültig
print("Hallo)
gültig
name = "Mia"
print(name)
ungültig
Print("Hallo")
Fehlermeldungen sind Hinweise. Lies zuerst die letzte Zeile der Meldung. Sie nennt meistens die Fehlerart und häufig auch die betroffene Zeile.

Python · Quellcode speichern

Python-Skripte sind .py-Dateien

In der Konsole gibst du eine Anweisung nach der anderen ein. Ein Skript speichert mehrere Anweisungen als Quellcode in einer Datei.

Konsole

Direkt ausprobieren

>>> 2 + 3
5
Skript

Später erneut starten

print("Hallo")
print(2 + 3)

Lege eine Datei hallo.py an:

print("Hallo aus einer Datei")
print(5 + 3)

Starte sie im Terminal aus dem gleichen Ordner:

python hallo.py

Eine .py-Datei ist Plain Text: Sie enthält nur Zeichen. Python deutet diese Zeichen nach den Syntaxregeln als Programm.

Python · Entwicklungsumgebung

VS Code einrichten

IDE bedeutet Integrated Development Environment, auf Deutsch Entwicklungsumgebung. Visual Studio Code bündelt Editor, Terminal, Erweiterungen und später Debugging an einem Ort.

1

VS Code öffnen

Den Kursordner als Ordner öffnen, nicht nur eine einzelne Datei.

2

Python-Erweiterung installieren

In den Erweiterungen nach Python suchen und die Microsoft-Erweiterung installieren.

3

Interpreter auswählen

Unten in VS Code die passende installierte Python-Version auswählen.

4

Terminal öffnen

In VS Code ein neues Terminal öffnen und python --version ausführen.

5

Erste Datei starten

hallo.py anlegen und mit python hallo.py ausführen.

Falls die Schule einen Proxy verwendet

Vor der Installation der Erweiterung braucht ihr von der IT die Proxy-Adresse, den Port, mögliche Anmeldedaten und gegebenenfalls ein Zertifikat. Diese Angaben werden zentral in VS Code eingerichtet; nicht raten und keine Sicherheitsprüfung abschalten.

"http.proxy": "http://proxy.beispiel.de:8080"

Die Adresse ist nur ein Muster. Die echte Proxy-Adresse muss von eurer IT kommen.

Python · Programme reagieren lassen

Eingaben und if-Anweisungen

Mit input() lesen wir Text von der Tastatur. Mit if entscheidet ein Programm, welche Anweisung unter einer Bedingung ausgeführt wird.

Name einlesen und ausgeben:

name = input("Wie heißt du? ")
print("Hallo", name)

Alter als Zahl behandeln und eine Bedingung prüfen:

alter = int(input("Wie alt bist du? "))

if alter >= 18:
    print("Du bist volljährig.")
else:
    print("Du bist minderjährig.")
Wichtig: Die Einrückung gehört zur Syntax. Die eingerückte Zeile gehört zur Bedingung direkt darüber.
alter >= 18größer oder gleichalter == 18genau gleichalter < 18kleiner als

Übung B · input und Variablen

Kioskbestellung

Erstelle kiosk.py. Frage nach einem Produkt und danach, wie viele Stück bestellt werden. Gib anschließend einen vollständigen Bestellsatz aus, zum Beispiel: „Du bestellst 3 Brezen.“ Teste auch eine andere Bestellung.

Übung C · Zahl und if

Paketannahme

Erstelle paket.py. Frage nach dem Gewicht eines Pakets in Kilogramm. Bis einschließlich 20 kg soll „Paket wird angenommen“ erscheinen, darüber „Paket ist zu schwer“. Prüfe dein Programm mit 12, 20 und 21.

Übung D · Text vergleichen

Geheimwort

Erstelle geheimwort.py. Frage nach einem Geheimwort. Nur bei der exakten Eingabe python soll „Zugang geöffnet“ erscheinen, sonst „Zugang verweigert“. Probiere auch Python mit großem P und erkläre das Ergebnis.

Übung E · Alles zusammen

Lagerbestand prüfen

In einem Lager liegen 12 Tastaturen. Frage, wie viele bestellt werden sollen. Reicht der Bestand, gib „Bestellung möglich“ und den verbleibenden Bestand aus. Andernfalls soll „Nicht genügend Tastaturen“ erscheinen. Teste mindestens die Bestellmengen 5, 12 und 15.
