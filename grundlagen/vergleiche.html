Vergleiche und Wahrheitswerte

Du wertest Vergleiche zu True oder False aus.

OperatorFrage
==Gleich?
!=Ungleich?
<Kleiner?
<=Kleiner oder gleich?
>Größer?
>=Größer oder gleich?

Ein Vergleich wie punkte >= 50 wird zu True oder False ausgewertet. Beide Werte haben den Typ bool. True ohne Anführungszeichen ist ein Wahrheitswert; "True" ist Text.

punkte = 62
bestanden = punkte >= 50
print(bestanden)
print(punkte == 62)
print(punkte != 62)

Die Ausgaben sind True, True und False. Die Grenze ist wichtig: > 50 schließt 50 aus, >= 50 schließt 50 ein. Vergleiche sollen sich auf passend vergleichbare Werte beziehen; ein int und ein String sind nicht automatisch dieselbe Zahl.

Selbstkontrolle

Welche Werte ergeben 5 >= 5 und 5 > 5?

Antwort vergleichen

True und False. >= schließt den gleichen Wert ein.
