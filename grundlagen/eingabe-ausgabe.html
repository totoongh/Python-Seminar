input und print

Du liest Eingaben als Text ein und wandelst sie für Rechnungen passend um.

input("Frage: ") zeigt die Frage an, wartet auf eine Eingabe und liefert deren Inhalt als String zurück. Auch beim Eintippen von 84 ist die Rückgabe zunächst "84". Für Rechnungen mit einer ganzen Zahl brauchst du z. B. int(input(...)).

text = input("Zahl: ")
zahl = int(text)
print(zahl + 1)
print("Eingabe:", text)

Bei Eingabe 84 wird nach der Frage 85 und anschließend Eingabe: 84 ausgegeben. Die Umwandlung erzeugt einen neuen Wert; text bleibt str. Die eingegebene Zeichenfolge ist selbst keine print-Ausgabe des Programms.

print stellt Werte für die Ausgabe dar. Es verändert den Typ der gespeicherten Variablen nicht. Mehrere Argumente werden standardmäßig durch Leerzeichen getrennt, jede print-Anweisung endet standardmäßig mit einem Zeilenumbruch. Die Rückgabe von print ist None.

Bei Aufgaben zu gültigen ganzen Eingaben ist gemeint, dass der Text zu int umgewandelt werden kann. Der Rückgabetyp von input bleibt trotzdem str.

Selbstkontrolle

Nach x = input("Zahl: ") wird 7 eingegeben. Hat x den Typ int?

Antwort vergleichen

Nein, x ist der String "7". Erst z. B. x = int(x) ordnet x den ganzzahligen Wert 7 zu.
