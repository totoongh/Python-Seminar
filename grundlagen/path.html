Ausführbare Dateien, Pfade und PATH

Du verstehst, warum ein vorhandenes Programm beim Aufruf trotzdem nicht gefunden werden kann.

Ein Pfad beschreibt den Ort einer Datei oder eines Ordners. Ein absoluter Pfad ist vollständig, etwa C:\Tools\Python\python.exe. Ein relativer Pfad bezieht sich auf das aktuelle Verzeichnis; .\python.exe meint diese Datei im aktuellen Ordner.

PATH ist eine Umgebungsvariable mit einer Liste von Verzeichnissen. Bei einem externen Befehl wie python sucht PowerShell unter anderem dort nach einer passenden ausführbaren Datei. PowerShell berücksichtigt auch eigene Befehlsarten, etwa Cmdlets und Aliase.

Existiert python.exe in C:\Tools\Python, wird aber nicht gefunden, kannst du diesen Ordner in PATH aufnehmen und eine neue Shell öffnen. Eingetragen wird der Ordner, nicht die einzelne EXE-Datei. Alternativ funktioniert ein direkter Aufruf:

& "C:\Tools\Python\python.exe" --version
# Oder im Ordner C:\Tools\Python:
.\python.exe --version

PowerShell startet eine Datei im aktuellen Ordner normalerweise nicht allein über ihren Namen. Die Schreibweise .\ macht den lokalen Pfad ausdrücklich. Das & führt einen in Anführungszeichen geschriebenen Programmpfad aus.

Selbstkontrolle

python.exe existiert, aber python wird nicht erkannt. Nenne zwei mögliche Lösungen.

Antwort vergleichen

Den Installationsordner zu PATH hinzufügen und die Shell neu öffnen; oder die EXE über ihren vollständigen Pfad aufrufen. Auch .\python.exe im passenden Ordner ist möglich.
