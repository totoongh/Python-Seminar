Rechenoperationen und Strings

Du kannst Rechenoperatoren lesen und Texte zusammensetzen.

OperatorBedeutungBeispiel
+Addition5 + 2 = 7
-Subtraktion5 - 2 = 3
*Multiplikation5 * 2 = 10
/Division; bei int-Eingaben float-Ergebnis5 / 2 = 2.5
//Ganzzahlige Division, abgerundet5 // 2 = 2
%Divisionsrest5 % 2 = 1
**Potenz2 ** 3 = 8

Klammern werden zuerst ausgewertet. Potenzen stehen vor Multiplikation/Division/Rest, diese vor Addition/Subtraktion. Gleichrangige Operationen wie + und - werden von links nach rechts ausgewertet.

text = "84"
n = 5
print(int(text) // (n + 1))
print(text + str(n - 2))
print("ha" * 3)

Ausgabe: 14, dann 843, dann hahaha. + fügt zwei Strings zusammen. Eine Zahl musst du dafür mit str(...) in Text umwandeln. String mal int wiederholt Text. String plus int ist keine gültige Addition. print("Wert:", n) kann mehrere Werte anzeigen, ohne sie vorher zu einem String zusammenzufügen.

Selbstkontrolle

Welchen Wert und Typ hat 8 / 4? Was ergibt "8" + "4"?

Antwort vergleichen

8 / 4 ergibt 2.0 vom Typ float. Die String-Verknüpfung ergibt "84" vom Typ str.
