Compiler und Interpreter

Du kannst Übersetzen und Ausführen zur Laufzeit unterscheiden.

Ein Compiler übersetzt Quellcode in Zielcode, etwa Maschinencode oder Bytecode. Dieser Zielcode kann anschließend ausgeführt werden. Ein Interpreter verarbeitet Code zur Laufzeit und veranlasst seine Ausführung.

Die Begriffe beschreiben Aufgaben von Software. Sie bedeuten nicht, dass eine Sprache immer ausschließlich die eine oder die andere Technik verwendet. Mischformen sind möglich.

Die verbreitete Python-Implementierung CPython übersetzt Python-Quellcode zunächst in Bytecode. Dieser wird anschließend von der Python-Laufzeit ausgeführt. Für die Grundlagen reicht: Compiler übersetzen Code; Interpreter verarbeiten ihn bei der Ausführung. „Python wird einfach Zeichen für Zeichen direkt von der CPU gelesen“ wäre falsch.

Selbstkontrolle

Erkläre kurz den Unterschied zwischen Compiler und Interpreter.

Antwort vergleichen

Ein Compiler übersetzt Quellcode in Zielcode. Ein Interpreter verarbeitet Code zur Laufzeit und führt ihn aus. Beide Techniken können kombiniert werden.
