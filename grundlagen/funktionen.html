Funktionen, Parameter, Argumente, return und print

Du definierst und rufst Funktionen auf und unterscheidest Rückgabe und Ausgabe.

Eine Funktion bündelt Anweisungen unter einem Namen. def name(parameter): ist die Definition, der eingerückte Block der Funktionskörper. Die Definition führt den Körper noch nicht aus. Erst name(argument) ruft ihn auf.

def verdoppeln(zahl):
    print("Start")
    return zahl * 2

ergebnis = verdoppeln(4)
print(ergebnis + 1)

Parameter ist die benannte Eingangsvariable der Definition, hier zahl. Ein Argument ist der beim Aufruf übergebene Wert oder Ausdruck, hier 4. Ausgabe: Start und 9. Der Aufruf liefert 8 zurück, sodass ergebnis auf 8 gesetzt wird.

print zeigt Werte an. return liefert einen Wert an den Aufrufer und beendet den aktuellen Funktionsaufruf. Ohne ausgeführtes return mit Wert liefert die Funktion None. Entfernst du oben die return-Zeile, wird ergebnis None; None + 1 führt dann zu einem Fehler.

def summe_bis(n):
    summe = 0
    zahl = 1
    while zahl <= n:
        summe = summe + zahl
        zahl = zahl + 1
    return summe

print(summe_bis(3))

Die Ausgabe ist 6. return steht nach der Schleife, damit alle Zahlen verarbeitet werden. Ein Zähler wächst bei einem Treffer um 1; eine Summe wächst um den jeweiligen Wert. Für n = 0 gibt diese Funktion 0 zurück.

Eine Methode ist eine an ein Objekt bzw. einen Typ gebundene Funktion, z. B. liste.append(wert). Die oben frei definierte Funktion verdoppeln wird ohne Objekt vor dem Namen aufgerufen.

Selbstkontrolle

Welche Rolle spielen zahl und 4 im ersten Beispiel, und welcher Wert wird in ergebnis gespeichert?

Antwort vergleichen

zahl ist der Parameter; 4 das Argument. Gespeichert wird die Rückgabe 8, nicht der angezeigte Text Start.
