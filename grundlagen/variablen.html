Variablen und Zuweisungen

Du verfolgst, welchen Wert ein Name nach einer Codezeile bezeichnet.

Mit = weist du einer Variablen einen Wert zu. Python wertet zuerst die rechte Seite aus und ordnet das Ergebnis dann dem Namen links zu. == prüft dagegen auf Gleichheit.

n = 3
ergebnis = 2
n = ergebnis + n * 2
ergebnis = n - 3
print(n, ergebnis)

Zuerst sind n = 3 und ergebnis = 2. In Zeile 3 wird mit den bisherigen Werten gerechnet: 2 + 3 · 2 = 8. Danach ist n = 8. Die nächste Zeile setzt ergebnis auf 5. Ausgabe: 8 5.

Ein Schreibtischtest notiert die Werte nach der jeweils ausgeführten Zeile. Arbeite in Ausführungsreihenfolge; spätere Änderungen verändern frühere Rechenschritte nicht nachträglich.

Selbstkontrolle

Welchen Wert hat n nach n = n + 1, wenn n zuvor 4 war?

Antwort vergleichen

5. Die rechte Seite verwendet den bisherigen Wert 4; anschließend wird das Ergebnis 5 zugewiesen.
