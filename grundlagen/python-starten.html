Python starten, Skripte und Editor

Du unterscheidest Python-Konsole, Skriptdatei und Editor.

Nach der Installation kannst du mit python --version prüfen, ob Python über diesen Befehl erreichbar ist. Ein Aufruf von python ohne Dateiname startet gewöhnlich die interaktive Konsole; dort steht der Prompt >>>. Dieser Prompt gehört nicht zu deinem Code.

Eine Skriptdatei, z. B. rechnung.py, enthält Python-Quellcode. Ein Editor wie VS Code hilft beim Schreiben. Der Editor selbst ist nicht der Python-Interpreter. Speichere die Datei, bevor du sie startest.

python rechnung.py

Den Befehl gibst du in der Shell ein, im Ordner der Datei oder mit ihrem Pfad. Ausgabe und Fehlermeldungen erscheinen im Terminal. Im Editor musst du ggf. den installierten Python-Interpreter auswählen.

Was ist der Unterschied zwischen rechnung.py und python.exe?

Antwort vergleichen

rechnung.py enthält den Quellcode deines Skripts. python.exe ist die ausführbare Python-Laufzeit, mit der du das Skript starten kannst.
