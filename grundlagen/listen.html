Flache Listen, append, len, Indizes und Slices

Du liest und veränderst eine eindimensionale Liste.

Eine Liste speichert eine geordnete Folge von Werten, geschrieben mit eckigen Klammern. Eine flache Liste enthält hier einzelne Werte statt weiterer Listen. Der erste Index ist 0, der letzte ist len(liste) - 1.

geraete = ["Maus", "Monitor", "Tastatur"]
geraete.append("Headset")
print(len(geraete))
print(geraete[1])
print(geraete[0:2])
geraete[0] = "Webcam"
print(geraete[0])

Ausgabe: 4, Monitor, ['Maus', 'Monitor'] und Webcam. append(wert) hängt ein Element an. Eine Zuweisung an einen bestehenden Index ersetzt ein Element und verändert die Länge nicht.

liste[start:stopp] liefert einen einfachen Ausschnitt als neue Liste. start ist enthalten, stopp ausgeschlossen. liste[:2] beginnt am Anfang; liste[1:] reicht bis zum Ende. liste[-1] bezeichnet das letzte Element. Ein einzelner Index außerhalb der Liste führt zu einem Fehler.

Methoden wie geraete.append(...) gehören zu einem Objekt. len(geraete) ist dagegen ein Funktionsaufruf. append verändert die Liste und gibt None zurück. Wenn ein Debugger vor einer Zeile anhält, wurde diese Zeile noch nicht ausgeführt.

Selbstkontrolle

Welche Werte liefert [4, 7, 9, 2][1:3]? Verändert das Ersetzen des ersten Elements die Länge?

Antwort vergleichen

Der Slice liefert [7, 9]. Ersetzen verändert die Länge nicht.
