Terminal und Shell

Du kannst das Eingabefenster und das darin laufende Befehlsprogramm unterscheiden.

Das Terminal stellt eine Oberfläche für Texteingabe und Textausgabe bereit. Die Shell ist das Programm, das deine Befehle interpretiert und ausführt oder weitere Programme startet. PowerShell ist eine Shell; Windows Terminal ist ein Terminal.

Ein Terminal kann unterschiedliche Shells anzeigen. Wenn du python eingibst, entscheidet die Shell, wie der Befehl gefunden und gestartet wird. Eine Fehlermeldung erscheint im Terminal, stammt aber vom beteiligten Programm, etwa der Shell.

PS C:\Users\Azubi> python --version
Python 3.13.0

Die Versionsausgabe hier ist ein Beispiel. Der Prompt PS …> gehört nicht zum Befehl. Du tippst nur python --version ein.

Selbstkontrolle

Ist PowerShell das Gleiche wie Windows Terminal?

Antwort vergleichen

Nein. PowerShell verarbeitet Befehle; Windows Terminal stellt das Fenster für Ein- und Ausgabe bereit.
