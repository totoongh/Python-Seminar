if, elif und else

Du schreibst eine Entscheidung mit korrektem Doppelpunkt und Einrückung.

Python prüft die Bedingungen einer if/elif/else-Kette von oben nach unten. Der Block der ersten wahren Bedingung wird ausgeführt. Die weiteren Zweige dieser Kette werden übersprungen. Trifft keine Bedingung zu, wird der optionale else-Block ausgeführt.

temperatur = 12
if temperatur < 0:
    print("Frost")
elif temperatur < 15:
    print("kuehl")
else:
    print("warm")
print("Fertig")

Ausgabe: kuehl, danach Fertig. Hinter if und elif steht eine Bedingung. Hinter else steht keine Bedingung. Jede Kopfzeile endet mit einem Doppelpunkt; der zugehörige Block ist eingerückt, üblicherweise mit vier Leerzeichen.

Mehrere einzelne if-Anweisungen sind keine gemeinsame Kette und können mehrere Ausgaben erzeugen. Die Reihenfolge der Bedingungen ist daher Teil deiner Lösung.

Selbstkontrolle

Was gibt der Code bei temperatur = 15 aus?

Antwort vergleichen

warm, danach Fertig. 15 < 15 ist False.
