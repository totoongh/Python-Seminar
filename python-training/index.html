Training · Methodik

KI als Lernhilfe – nicht als Abgabe-Automat

KI kann dir in Sekunden jede unserer Aufgaben lösen. Genau deshalb bringt es nichts, sie das tun zu lassen: Du lernst Programmieren nur, wenn dein Kopf die Arbeit macht. Im Betrieb und in der Prüfung musst du Code verstehen, prüfen und reparieren – auch den Code, den eine KI geschrieben hat.

🟢 Grün – immer okay
  • „Erklär mir diese Fehlermeldung in einfachen Worten.“
  • „Erklär mir den Unterschied zwischen return und print mit einem Beispiel, das nicht meine Aufgabe ist.“
  • „Stell mir 5 Quizfragen zu while-Schleifen.“
  • „Gib mir einen Hinweis, keine Lösung.“
🟡 Gelb – erst nach eigenem Versuch
  • „Hier ist mein Code. Wo könnte ein Fehler sein? Sag mir nur die Zeile, nicht die Korrektur.“
  • „Mein Programm funktioniert. Was könnte ich besser machen?“
  • „Gib mir eine ähnliche Übungsaufgabe.“
🔴 Rot – bringt dir nichts
  • Aufgabentext reinkopieren: „Löse das.“
  • Code übernehmen, den du nicht Zeile für Zeile erklären kannst.
  • KI-Code abgeben, ohne es zu sagen.
Die drei Regeln

So nutzen wir KI im Seminar

  • Erst selbst: Mindestens 10 Minuten eigener Versuch, bevor du fragst.
  • Erklär-Test: Du musst jede Zeile deiner Abgabe mündlich erklären können. Ich frage stichprobenartig nach.
  • Ehrlich markieren: Wenn eine Idee von der KI kommt, schreib einen Kommentar dazu: # Idee von KI: ...

Training · Code aufräumen

Refactoring: Der Getränkeautomat

Refactoring heißt: Code umbauen, ohne dass sich sein Verhalten ändert. Das Programm unten funktioniert – ist aber ein langer Block. Zerlege es in Funktionen.

Ausgangscode

Funktioniert, aber unübersichtlich

Kopiere den Code in eine neue Datei automat.py (oder herunterladen) und probiere ihn einmal aus.

getraenke = ["Wasser", "Cola", "Saft"]
preise = [1.0, 1.5, 2.0]

while True:
    print("--- Getränkeautomat ---")
    for i in range(len(getraenke)):
        print(i + 1, getraenke[i], preise[i], "€")
    print("0 Ende")

    auswahl = input("Auswahl: ")
    if auswahl == "0":
        print("Tschüss!")
        break
    if auswahl not in ["1", "2", "3"]:
        print("Ungültige Auswahl.")
        continue

    nummer = int(auswahl) - 1
    preis = preise[nummer]

    geld = float(input("Geld einwerfen: "))
    while geld < preis:
        print("Zu wenig! Es fehlen", round(preis - geld, 2), "€")
        geld = geld + float(input("Nachwerfen: "))

    rueckgeld = round(geld - preis, 2)
    print("Hier ist dein", getraenke[nummer])
    if rueckgeld > 0:
        print("Rückgeld:", rueckgeld, "€")
Stufe 1Mit Gerüst – für alle
Aufgabe

Diese Funktionen sollen entstehen

  • zeige_menue() – gibt nur das Menü aus.
  • ist_gueltige_auswahl(auswahl) – gibt True/False zurück.
  • berechne_rueckgeld(geld, preis) – gibt das gerundete Rückgeld zurück.
  • geld_einsammeln(preis) – fragt so lange Geld ab, bis es reicht, und gibt die Summe zurück.
  • Die Hauptschleife ruft nur noch diese Funktionen auf.

Testfall: Eingaben 2, 1, 1, 5, 0 müssen vorher und nachher exakt dieselbe Ausgabe erzeugen.

Stufe 2Ohne Gerüst – für Fortgeschrittene
Aufgabe

Selbst entscheiden

  • Überlege selbst, welche Funktionen sinnvoll sind. Jede Funktion soll genau eine Sache machen.
  • Pack die Hauptschleife in eine Funktion main().
  • Schreibe für berechne_rueckgeld drei assert-Tests, z. B. assert berechne_rueckgeld(2.0, 1.5) == 0.5.
  • Extra: Füge ein viertes Getränk hinzu. Wie viele Stellen musst du ändern? (Tipp: ["1", "2", "3"] ist fest eingebaut – geht das besser?)

Musterlösung

Eine mögliche Aufteilung

getraenke = ["Wasser", "Cola", "Saft"]
preise = [1.0, 1.5, 2.0]


def zeige_menue():
    print("--- Getränkeautomat ---")
    for i in range(len(getraenke)):
        print(i + 1, getraenke[i], preise[i], "€")
    print("0 Ende")


def ist_gueltige_auswahl(auswahl):
    return auswahl in ["1", "2", "3"]


def geld_einsammeln(preis):
    geld = float(input("Geld einwerfen: "))
    while geld < preis:
        print("Zu wenig! Es fehlen", round(preis - geld, 2), "€")
        geld = geld + float(input("Nachwerfen: "))
    return geld


def berechne_rueckgeld(geld, preis):
    return round(geld - preis, 2)


def verkaufe(nummer):
    preis = preise[nummer]
    geld = geld_einsammeln(preis)
    rueckgeld = berechne_rueckgeld(geld, preis)
    print("Hier ist dein", getraenke[nummer])
    if rueckgeld > 0:
        print("Rückgeld:", rueckgeld, "€")


def main():
    while True:
        zeige_menue()
        auswahl = input("Auswahl: ")
        if auswahl == "0":
            print("Tschüss!")
            break
        if not ist_gueltige_auswahl(auswahl):
            print("Ungültige Auswahl.")
            continue
        verkaufe(int(auswahl) - 1)


main()

Extra-Aufgabe: 1 <= int(auswahl) <= len(getraenke) bzw. auswahl in [str(n) for n in range(1, len(getraenke) + 1)].

Training · Fehler finden

Bug-Suche

Jedes Programm enthält genau einen Fehler. Finde ihn zuerst auf Papier: Welche Zeile? Was passiert? Wie korrigierst du ihn? Erst danach darfst du ausprobieren.

SchemaZeile · Was passiert? · Korrektur
Bug 01 · leicht

Volljährig?

alter = input("Alter: ")
if alter >= 18:
    print("Volljährig")
else:
    print("Minderjährig")
Lösung

Zeile 1: input liefert Text → TypeError beim Vergleich. Korrektur: int(input(...)).

Bug 02 · leicht

Note prüfen

note = int(input("Note: "))
if note = 1:
    print("Sehr gut!")
Lösung

Zeile 2: = ist Zuweisung → SyntaxError. Vergleich mit ==.

Bug 03 · leicht

Countdown

zahl = 5
while zahl > 0:
    print(zahl)
print("Start!")
Lösung

Endlosschleife: zahl wird nie kleiner. In der Schleife zahl = zahl - 1 ergänzen.

Bug 04 · mittel

Abfrage

antwort = input("Weiter? (ja/nein) ")
if antwort == "ja" or "j":
    print("Es geht weiter.")
else:
    print("Ende.")
Lösung

Zeile 2: "j" allein ist immer wahr → es geht immer weiter. Korrekt: antwort == "ja" or antwort == "j".

Bug 05 · mittel

Summe der Liste

zahlen = [5, 10, 20]
summe = 0
for i in range(1, len(zahlen)):
    summe = summe + zahlen[i]
print(summe)   # soll 35 sein
Lösung

Zeile 3: Index startet bei 0 → das erste Element fehlt, Ausgabe 30. range(len(zahlen)) oder for zahl in zahlen.

Bug 06 · mittel

Letzter Eintrag

namen = ["Ali", "Bea", "Cem"]
print("Zuletzt:", namen[len(namen)])
Lösung

IndexError: Letzter Index ist len - 1. Besser: namen[-1].

Bug 07 · knifflig

Mehrwertsteuer

def brutto(netto):
    ergebnis = netto * 1.19

preis = brutto(100)
print("Brutto:", round(preis, 2))
Lösung

Kein return → preis ist None → TypeError bei round. return netto * 1.19.

Bug 08 · knifflig

Durchschnitt

punkte = [3, 7, 8]
summe = 0
for p in punkte:
    summe = summe + p
    print("Schnitt:", summe / len(punkte))
Lösung

Letzte Zeile ist zu weit eingerückt → wird dreimal mit Zwischenständen ausgegeben. Ausrücken.

Bug 09 · knifflig

Zähler

anzahl = 0

def hochzaehlen():
    anzahl = anzahl + 1

hochzaehlen()
print(anzahl)
Lösung

UnboundLocalError (vgl. Snippet 9). Sauber: def hochzaehlen(anzahl): return anzahl + 1 und anzahl = hochzaehlen(anzahl).

Bug 10 · knifflig

Größte Zahl

def groesste(zahlen):
    maximum = 0
    for z in zahlen:
        if z > maximum:
            maximum = z
    return maximum

print(groesste([-5, -2, -9]))   # soll -2 sein
Lösung

Logikfehler: Start bei 0 → Ergebnis 0. Start mit maximum = zahlen[0].

Aufgabe P3

Bring die Zeilen in die richtige Reihenfolge – und rück sie ein

Das Programm soll so lange Zahlen einlesen, bis 0 eingegeben wird, und dann die Summe ausgeben. Eine Zeile ist überflüssig!

Lösung

zahl = int(input("Zahl: "))
while zahl != 0:
    summe = summe + zahl
    zahl = int(input("Zahl: "))

# überflüssig: summe = 1
